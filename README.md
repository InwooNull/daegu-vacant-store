# 빈 점포 한 칸, 장사할 곳인가 쉼터가 될 곳인가

2026 대구 AI 드래프톤 과제 2-2(우리 동네 빈 공간, AI로 쓰임 찾기) · 팀 16비트

대구 빈 점포(추정)마다 **창업하면 3년 버틸 확률**과 **주민에게 모자란 생활시설**을 함께 계산해, 민간 창업으로 연결할지 구청이 공공 시설로 쓸지 판정합니다. 판정은 참고 자료이고 결정은 구청 담당자가 합니다.

- 사이트: `docs/` (GitHub Pages)
- 계산: `pipeline/` (Python, 공공데이터포털 공개 파일)
- 데이터 형식(팀원 모델로 바꿀 때): [DATA_FORMAT.md](DATA_FORMAT.md)
- 학습된 모델: `models/survival_model.txt`(LightGBM), 검증 결과 `models/model_metrics.json`

## 계산 순서
| 스크립트 | 하는 일 |
|---|---|
| `p1_dong.py` | SGIS 행정동 경계·2024 통계 → 동별 인구 구성 |
| `p2_vacancy.py` | 상가정보 분기 파일 비교 → 빈 점포(추정) 자리 |
| `p3_features.py` | 인허가 개업·폐업으로 자리 특징(주변 같은 업종 수, 최근 폐업, 과거 생존율 등) |
| `p4_public.py` | 경로당·도서관·돌봄센터 도보권 결손 점수, 동네 유형(K-평균) |
| `p5_model.py` | 업종별 3년 생존 모델(LightGBM), 시간 분할 검증 |
| `p6_export.py` | 판정 규칙 적용, 사이트용 JSON |

원자료는 저장소에 넣지 않았습니다(용량). `_데이터/대구/` 폴더 구조로 내려받은 뒤 `python -I pipeline/p1_dong.py`부터 차례로 실행합니다.

## 한계
- 빈 점포는 상가정보에서 사라진 자리로 **추정**한 것입니다. 이전·자료 누락이 섞일 수 있어 현장·건축물대장 확인이 필요합니다.
- 생존 확률은 인허가 신고 기준이고 매출을 뜻하지 않습니다. 업종 안에서 가려내는 힘(AUC)은 평균 0.57로 크지 않아, 예측력이 낮은 업종은 판정에 쓰지 않고 참고로만 보여 줍니다.
- 학교 돌봄교실·사설 시설과 일부 경로당 좌표가 빠져 결손이 실제보다 크게 나올 수 있습니다.
